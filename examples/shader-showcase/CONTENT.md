# 黑洞与闪电介绍视频制作稿

形式：1920×1080 / 30 fps / 简体中文字幕 / 无配音。游戏素材由独立 Forge 开发客户端的真实 framebuffer 捕获。视频只做文字说明与剪辑，不用后期特效冒充 Mod 渲染。

公开项目：https://github.com/Roxio-sketch/minecraft-agent-skills

已核对公开 Release：vfx-workbench-0.1.0-20261010。附件包含两个 Skill ZIP、演示 Mod JAR、Mod 源码 ZIP 与 SHA256SUMS。

黑洞视频的核心内容：

1. 先展示世界黑洞，再说明它可以自定义。
2. 对照尘埃、颗粒、层叠光带与经典光带。除体积尘埃外均已补拍，通过现有材质参数调整曝光、密度、厚度、配色和相机。
3. 在相同视角下对照金橙、冰蓝与紫色配色。
4. 实际改变盘面倾角、厚度、差速旋转与径向内流。
5. 展示独立粒子与世界背景透镜开关，说明场景颜色与深度的参与。
6. 实际拖动核心半径、厚度、倾角、旋转、内流、粒子速度、透镜强度与范围，并通过真实颜色选择器修改颜色。UI 与主体分区呈现。
7. 增加白洞明亮核心、双极喷流、外向粒子、外扩光壳，以及核心光晕、喷流强度、光壳强度的实际调参。
7. 说明 Skill → 工作台/配方 → Forge 示例/演示 Mod 的使用路线，提供开源地址。

闪电视频的核心内容：

1. 先展示自定义落雷，说明 orbit / strike / rain 三种通道。
2. 同配方换 seed 对照拓扑，同 seed 改分叉预算对照密度。
3. 展示起始色占比 0–100 的变化，说明核心/光晕可以分别选择渐变层。
4. 展示环绕延伸电流、环形电弧、集束群雷、散布群雷和击地尾段。
5. 载入五行仙途 `assets/wuxingxiantu/tribulation/08.json` 的高阶雷劫配方，保留 129 格高度、种子 81234、高密度分叉与四次回击。远景版本增加主雷线宽、光晕宽度与增益；彩色开场另改渐变作用层与端点色。记录实际最终配方，不声称复现完整游戏雷劫。
6. 实际拖动主雷宽度、光晕宽度、核心亮度、渐变比例、光晕亮度、分叉概率/深度/预算、群雷数量/散布范围及击地半径。
7. 提供自然语言需求示例、开源资源入口与集成边界。

准确性边界：

- 黑洞是美术化实时渲染，不宣称科学精确的广义相对论模拟。
- 演示 Mod 的闪电是客户端视觉，不能声称它自带服务器伤害逻辑。
- 不宣称网页工作台和 Minecraft 逐像素一致；外部 shader pack 兼容需另验。
- 本轮录制不是性能基准，不提供未经测量的 FPS 或“所有电脑流畅”承诺。
- 不为了录制修改五行仙途的僵直机制；若补录，单独说明使用的真实项目。

录制源码：../capture-mod。它是生产源码的隔离副本，新增视频调度、framebuffer 采集与录制专用 UI 适配。录制模式缩窄面板、侧置颜色选择器并取消颜色编辑的全屏遮罩，通过真实滑块和颜色输入回调调参。原着色器项目与开源仓库未修改。

时间轴时长：黑洞 / 白洞 3:40；闪电 3:15。BGM 已加入：黑洞用 The Spaces Between，闪电用 Helios，均为 Scott Buckley / CC BY 4.0，详见 MUSIC-CREDITS.md。曼波配音尚未取得，当前为无配音加 BGM 预览。封面使用实际 Minecraft 渲染帧。
