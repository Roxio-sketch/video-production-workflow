# 自定义 Minecraft 黑洞、白洞与闪电

两个视频均为 1920×1080、30 fps、简体中文字幕，提供曼波配音版和无配音配乐版。黑洞 / 白洞 4:06，闪电 3:15。2026-10-12 更新为连贯解说：用相邻镜头之间的过渡说明代替逐条朗读画面标签，透镜相关内容集中展示。配音时自动压低背景音乐，并保留立体声配乐。画面直接采集 Minecraft framebuffer，系统弹窗和桌面遮挡不会进入素材。录制使用独立开发客户端与专用存档。

曼波配音通过本机 `E:\MamboTTS` 的 Tsukimisaka/MamboTTS 1.2.1 社区预设生成，使用 GPT-SoVITS 和随附的 `manbo_e8_s168.pth`、`manbo-e10.ckpt`。未确认与剪映“曼波讲故事”完全一致；音色与自然度受该模型限制。新配音保留原始声调，不进行变调，主要使用原速，最长句的节奏调整小于 5%。两条片分别包含 39 / 29 个配音窗口。配音最终文案、实际朗读时间的 SRT、独立 WAV 和模型来源记录在 `配音准备`。普通男声云希和女声晓晓的试听保存在 `配音试听`，未用于正式版。

无配音成片的检查见 `成片检查.json`；曼波版的完整音视频解码、时长、分辨率、配音窗口、响度与画面码流校验见 `曼波配音成片检查.json`。配音版复制对应无配音成片的画面码流，混入配音时不再压缩画面。

## 黑洞 / 白洞

盘面风格与配色对照、盘面形状和运动、独立粒子、真实世界背景透镜、实际 Mod 多参数调节。透镜内容按“开关对照 → 范围 3 / 12 → 第三人称玩家参与关闭 / 开启 → 工作台实际调强度与范围”连续排列；不再隔着其他调参章节重复回到透镜。人物对照包含头盔和身体。白洞展示核心光晕、双极喷流、向外运动的粒子与外扩光壳。

体积尘埃保留现有素材；颗粒盘、层叠光带和经典光带已重新调参补拍，同时更新开场、配色和调参镜头。电影盘已移除。层叠光带扩大盘面外半径、减小偏折与相对论式亮度偏置，以改善两侧盘面的宽度；封面已更新为补拍素材。

## 闪电

环绕电流、分形落雷、固定 seed、分叉、渐变、群雷与击地放电，以及真实 Mod 多参数调节。四段调参镜头固定在真实闪电事件的第 4 tick，并关闭闪烁，便于持续观察形状、颜色和亮度变化；普通展示仍播放事件时间变化。开场使用五行仙途高阶雷劫 `08.json` 作为起点，在演示 Mod 中调节线宽、亮度与配色，以适合远景观看。并非五行仙途完整游戏机制的录屏。
