# 配音、字幕与音乐

历史案例采用本机 GPT-SoVITS / MamboTTS 社区音色，接口为本机 HTTP；它不是剪映官方“曼波讲故事”。完整配音模型、参考音频和音乐不分发。模型与音色使用资格由使用者核实。

`examples/shader-showcase/scripts` 保存原生成、切句、混音、ASR 和短版配音方法；含案例参数和历史路径，阅读后改为自己的 FFmpeg、服务、参考音频和文稿再执行。这些脚本不是通用一键安装程序。不要上传凭证，也不需要为基础工作台提供凭证。

先生成原速片段，试听后按实际 WAV 时长排镜头和字幕。数字/术语可改为自然朗读形式；保持画面事实不变。字幕与声音按真实时长切换，竖版短句重新组织，不挤压横版音轨。保留原始文案、WAV、时间清单、SRT 和来源。

案例音乐来源和 CC BY 署名在 MUSIC-CREDITS.md；音频未随仓库提供。其他视频重新确认来源与许可。混音需试听音乐掩盖旁白、峰值、转场与片尾；ASR 相似度不是人耳验收。
