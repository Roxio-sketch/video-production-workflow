# 绕过剪映的曼波配音方案

查询日期：2026-10-12。以下已核对项目作者文档、发布资产或模型文件，但尚未安装、合成或试听；不能确认与剪映「曼波讲故事」完全相同。

| 方案 | 输入 / 输出 | 适合本项目的方式 | 当前确认范围 |
| --- | --- | --- | --- |
| [MamboTTS](https://github.com/Tsukimisaka/MamboTTS) | 文案 → WAV | 优先候选：按旁白章节生成，再加入 Remotion | Windows 10/11、NVIDIA、本地 GPT-SoVITS；首次引擎约 8.2GB，建议预留 30GB+；随后可离线合成 |
| [RVC](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) + [卡通-曼波模型](https://huggingface.co/chaye741/RVC-Voice-Models/tree/main/weights) | 已有干声录音 → 改变音色的录音 | 已有解说时使用；先分离人声，转换后与 BGM 混音 | 已确认 `卡通-曼波.pth` 和 [配套 index](https://huggingface.co/chaye741/RVC-Voice-Models/tree/main/indices) 存在；该模型实际效果和 Windows 推理兼容性待验证 |
| [抖虫在线配音](https://www.dousnap.com/ai-voice-generator) | 文案 → 在线配音 | 快速试听的备选 | 网页列出「曼波」、试听、语速和情感控制；实际生成、收费额度与服务可用性未验证，也未找到公开 API 文档 |

MamboTTS 已核实 [v1.2.1 发布包](https://github.com/Tsukimisaka/MamboTTS/releases/tag/v1.2.1) 约 223MB，含客户端与预设音色，引擎另行下载。源码 `engine_contract.py` 约定模型文件 `manbo_e8_s168.pth`、`manbo-e10.ckpt` 和参考录音 `refer.wav`；调用本机 HTTP 接口 `127.0.0.1:9880`。本机 RTX 4060 Ti 16GB 属于其支持的 NVIDIA 类型，实际生成速度尚未测试。解压与引擎路径需全英文，可放在 E 盘。

建议先用本地 MamboTTS 生成一小段试听，确认音色后，再按现有配音稿分段生成。首次下载安装仍需联网，但后续合成无需剪映登录、素材服务或网络连接。使用本地 API 可以继续自动完成旁白生成、时长对齐和混音。

另有 [AstrBot 曼波 TTS 插件](https://github.com/zoffyultraman/astrbot_plugin_manbo-tts)，但其 README 明确写着目前不提供公共 API 服务，不作为立即可用方案推荐。
