## 保留原文及边界

产品名称、编码格式、快捷键键名、文件名、路径、组件/属性/代码标识符保留原值。视频画布、输入框、代码区不进行 DOM 文案替换。

用户代码抛出的任意错误、FFmpeg/Chromium/系统返回的原始诊断、第三方组件自己的文案、外部文档和在线版本说明不属于可穷尽的内置语言资源，仍可能显示英文。尚未触发每种错误或安装所有可选模块验证全部分支。因此这是全面补齐后的本地适配，不能保证所有动态或外部内容完全中文化。

DOM 补全只使用已维护的中文词典，不调用在线翻译、不上传文本、不改官方渲染器。它是维护补丁；官方升级后仍需重新兼容检查。

## 目录与启动

主工程：E:\Remotion\remotion-studio
测试工程：E:\Remotion\remotion-zh-test
兼容资源：E:\Remotion\remotion-zh-compatible-4.0.534
官方资源备份：E:\Remotion\backups\pre-zh-20261010-01\studio-dist

先停止已有主工程/测试工程 Studio 服务（终端 Ctrl+C），再双击主工程内“启动中文版.cmd”。主工程打开 http://localhost:3000/Landscape。

恢复英文：先停止两个 Studio 服务，再双击主工程内“恢复英文版.cmd”，或在主工程运行 npm.cmd run restore:studio-en 后 npm.cmd run dev。恢复只还原官方展示资源，保留视频修改。测试项目通过 node_modules 链接共用官方依赖，会同步恢复英文。

REMOTION_ZH_STUDIO_DIST 在中文启动脚本中仅为当前进程设置，不修改系统环境变量。

## 维护与更新

新增主要词典为 scripts/studio-zh-complete.json，旧的 extra/more/final 词典仍按顺序载入。只用于相同 4.0.534 版本时：停止 Studio，运行 npm.cmd run restore:studio-en，修改词典，再运行：

```powershell
node scripts/build-studio-zh.cjs
node scripts/verify-studio-zh.cjs
npm.cmd run apply:studio-zh
npm.cmd run dev
```

verify 会对比本轮保存的源码快照。以后自行改视频造成源码不一致时，先确认更改是预期的，再更新快照；不要通过还原旧源码来消除检查错误。

官方版本升级时不能套用旧资源。应先恢复英文、备份工程，再保存新官方版本 dist、适配生成器和版本信息、重新验证编辑与渲染。apply 有版本和哈希检查，会拒绝未知资源。
